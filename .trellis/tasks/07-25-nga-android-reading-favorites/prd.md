# NGA Android 浏览渲染与收藏排序

## Goal

在已验证的数据与会话基础上，以 Justwen 已有的版面、主题、帖子 UI、导航和主题样式为唯一视觉基线，补齐 `nga_harmony` 的浏览、搜索、历史、富文本、自适应行为，并实现“我的收藏”版面直接长按拖动排序。

## Dependencies

- 必须先完成 `07-25-nga-android-foundation-access`，并使用其账号、网络、错误、数据模型和存储契约。
- 不得在本任务中绕过或私自替换基础任务判定为不可用的接口。

## Requirements

1. 产品布局、导航、主题、设置和信息密度完全保留 Justwen；`nga_harmony` 只提供功能清单和自适应行为线索，不得重做 Android 视觉层。
2. 实现版面/分类、主题列表、分页/筛选、帖子详情、楼层分页/跳转、引用/折叠、热门回复、搜索和浏览历史。
3. BBCode 解析为纯 Kotlin AST，HTML 降级归一到同一内容模型；图片、链接、表格、代码、列表、引用、折叠、表情和损坏标签必须安全降级。
4. Room 作为缓存与持久化事实来源；主题列表使用 Paging 3，帖子详情使用可前后翻页和跳页的显式 page store。
5. 收藏版面是整个 App 共享的一份版面 membership/order：服务端 membership（若可用）与本地全局顺序覆盖层合并；稳定键为 `fid + stid`，不包含账号或当前数组下标。账号会话/私有缓存仍按账号隔离，但不改变这份版面收藏。
6. 在“我的收藏”网格中，短按版面卡片/按钮继续打开版面；长按卡片成功后直接拖动该项调整顺序。不得长按版面页 `menu_add_bookmark`，不得先进入页面级排序模式或跳转页面；长按不改变 membership。释放后事务保存；保存失败回滚；服务端刷新保留幸存项相对顺序、删除失效项、去重并将新项追加到末尾。
7. “我的收藏”所在的 `HorizontalPager` 与拖动必须仲裁：长按成立前先横向滑动时，正常切换到右侧分类（例如“魔兽世界”）；长按成立后临时禁用 Pager 用户横滑并消费本次拖动，横向移动只在收藏网格内重排；抬起、取消或回滚后恢复分页。
8. TalkBack 用户必须有等价的上移、下移、置顶和置底操作；拖动不能是唯一排序方式。
9. 保持当前分叉 `minSdk 29`、`compile/target 35`；Android 15/API 35 是现代自适应、高刷新率和完整功能的主门。API 29 最低安装/核心 smoke 与 API 36 上 `targetSdk 35` 前向 smoke 仅在用户提供匹配实体设备时补充，不启动模拟器，也不把缺少这些可选设备作为阻塞。

## Acceptance Criteria

- [ ] 用户可完成“选择版面 → 浏览主题 → 阅读帖子 → 搜索/跳页/查看图片”的完整只读流程。
- [ ] compact/medium/expanded 布局切换不会丢失当前版面、主题、帖子页、滚动锚点或未完成操作。
- [ ] 合法和损坏 BBCode/HTML fixture 均不会导致崩溃、无限循环或将挑战页显示为空内容。
- [ ] 已缓存内容在离线时可明确标记为缓存后展示；刷新、空态、登录过期、挑战、站点消息和解析失败彼此可区分。
- [ ] 短按“我的收藏”版面卡片仍打开对应版面；长按卡片后可直接拖动排序，不出现额外排序入口、不跳页、不改变收藏 membership。
- [ ] 手势仲裁可观察：长按前横滑能切换“魔兽世界”等分类；长按成立后横向拖动不翻页，只移动网格项；抬起/取消后下一次横滑立即可切页。
- [ ] 页面退出/进程重启后顺序保持；切换账号不会替换或重置这份 App 级版面收藏；服务端刷新、重复项、空列表、保存失败和 TalkBack 等价操作均通过测试。
- [ ] Android 15/API 35 的长主题/帖子列表、富文本、图片查看和收藏拖动达到父设计中的性能门槛；可用时附 API 29 最低 smoke 与 API 36 前向 smoke 报告。

## Out of Scope

- 发帖、回复、上传、私信、通知、投票和 AI；由后续子任务负责。
