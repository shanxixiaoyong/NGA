# 收藏页分页边界滑动打开侧栏

## Goal

让首页水平导航呈现“侧栏｜我的收藏｜魔兽世界｜其他版面”的相邻关系：用户在“我的收藏”的分页内容区向侧栏方向完成一次翻页手势后，打开现有侧栏；向相反方向翻页仍按现有行为进入“魔兽世界”。

## Background

- 首页数据固定先加入“我的收藏”，再加入本地版面，因此收藏页是 `HorizontalPager` 的第 0 页，后续页包含“魔兽世界”：`ForumBoardModel.kt:75-80`。
- 已发布实现把侧栏打开手势限定在屏幕左侧 24dp，并添加了 `systemGestureExclusion`；这不符合“侧栏是收藏页左侧相邻页”的交互模型：`NavigationDrawerFragment.kt:311-347`（HEAD）。
- 收藏页到“魔兽世界”的现有分页路径由 `HorizontalPager` 处理，本任务不替换该路径：`TabLayoutWithPager.kt:51-54`（HEAD）。
- 用户已选择“手势完成后再打开侧栏”：侧栏使用现有打开动画，不要求拖拽过程中跟随手指。

## Requirements

- R1. 侧栏打开手势只在“我的收藏”的 `HorizontalPager` 内容区域生效，不覆盖顶部工具栏、分页标签栏或首页其他区域。
- R2. 手势必须从已稳定停靠的第 0 页开始，并朝侧栏所在的左侧相邻页方向完成；可从收藏页内容区任意水平位置起手，不设 24dp 边缘限制。
- R3. 手势松开时，水平位移达到页面宽度的 50%，或朝侧栏方向的速度达到 400dp/s，才调用现有侧栏打开动画；未达到门槛、垂直手势或取消手势不得打开侧栏。
- R4. 收藏页向“魔兽世界”方向的手势继续完全交给现有 `HorizontalPager`，其方向、门槛、动画和结果不变。
- R5. 从“魔兽世界”或更后面的页面开始的手势只能由分页处理；不得越过“我的收藏”直接打开侧栏。
- R6. 删除 24dp 边缘宽度、边缘命中函数和为其添加的 `systemGestureExclusion`，并禁止关闭状态下 Material 抽屉自身的默认边缘打开手势。
- R7. 保留首页左上角三横线菜单图标、辅助功能描述和点击打开侧栏；其他页面仍默认使用返回箭头。
- R8. 收藏项长按拖拽排序激活时，不响应侧栏边界手势，也不恢复被排序逻辑禁用的分页手势。
- R9. 侧栏打开后仍保留拖动关闭、回弹和点击遮罩关闭行为。
- R10. 本功能作为新的稳定版本 `4.7.2` 发布；tag 必须指向 finish-work 后的最终 `main` 提交并推送到 `origin`，由现有 GitHub Actions 生成正式 Release。

## Acceptance Criteria

- [ ] AC1 (R1, R2): 在“我的收藏”的分页内容区从左侧、中间或右侧起手，朝侧栏相邻页方向完成有效手势后，侧栏使用现有动画打开；同样手势从工具栏或标签栏起手不会打开侧栏。
- [ ] AC2 (R3): 位移达到页面宽度 50% 可打开侧栏；位移不足但朝正确方向达到 400dp/s 也可打开；两项都不足时不打开。
- [ ] AC3 (R3): 反方向、垂直占优、手势取消或分页在起手时未稳定，均不打开侧栏。
- [ ] AC4 (R4): 从“我的收藏”执行现有分页手势后仍进入“魔兽世界”，且不打开侧栏。
- [ ] AC5 (R5): 从第 1 页或更后页面开始的任意水平手势不会直接打开侧栏；必须先回到“我的收藏”，再完成一次独立的侧栏方向手势。
- [ ] AC6 (R6): 产品代码中不再存在 `DrawerEdgeWidth`、`isWithinDrawerEdge`、`systemGestureExclusion` 或废弃原型的 `HomeHorizontalGestureOwner`。
- [ ] AC7 (R7): 首页三横线按钮仍可打开侧栏，其辅助功能描述仍为“打开侧边栏”；共享顶栏默认返回图标不变。
- [ ] AC8 (R8): 收藏长按排序期间，水平拖动只服务排序，不打开侧栏或切换分页；排序结束或取消后交互恢复。
- [ ] AC9 (R9): 侧栏开启后的拖动关闭和遮罩点击关闭仍由 Material 抽屉处理。
- [ ] AC10: 边界方向、50% 位移、400dp/s 速度、后续分页、垂直手势、排序抑制、抽屉手势门控和菜单辅助功能均有自动化覆盖；受影响模块编译、单测和 lint 通过。
- [ ] AC11 (R10): `main` 和 annotated tag `4.7.2` 均已推送；tag 指向最终 HEAD，并触发稳定 Release 工作流。稳定 `versionName` 和 `versionCode` 分别继续由 tag 与 CI run number 注入，不硬改本地开发版本。

## Out of Scope

- 不实现侧栏随手指连续拖出，也不新增首页专用抽屉容器。
- 不在全首页表面或系统返回手势边缘增加打开侧栏的手势。
- 不改变侧栏内容、宽度、颜色、账户信息或打开动画。
- 不改变版面顺序、收藏数据、排序交互或持久化。
- 不把侧栏加入 `HorizontalPager` 作为普通全屏页。
- 不改写现有 GitHub Actions 发布流程或手动上传 APK；发布资产继续由 tag 工作流构建。

## Key Decisions

- “左滑/右滑”按目标相邻页描述；实现与测试使用逻辑上的“侧栏方向”和“后续分页方向”，避免把手指位移与页面目标混为一谈。
- 采用用户确认的第二种方案：旁观分页内容区的完整手势，松手满足 Pager 对等门槛后再打开侧栏，侧栏不跟手。
- 观察器不消费指针事件；分页能处理的方向继续由原 `HorizontalPager` 独占。
- 当前没有未决的产品或范围问题。
