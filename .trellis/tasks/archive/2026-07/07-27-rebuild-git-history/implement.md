## Validation Commands

The implementation may wrap these in task-local scripts, but must retain equivalent explicit assertions:

```bash
git merge-base <candidate-tip> 5d807617f8058950f7ea81dda405e38fb0cc37ec
git rev-list --count 5d807617f8058950f7ea81dda405e38fb0cc37ec..<candidate-tip>
git rev-parse <old-tip>^{tree} <candidate-tip>^{tree}
git fsck --full
git ls-remote origin refs/heads/main 'refs/tags/*' 'refs/tags/*^{}'
gh api repos/tophtab/nga-just-works
gh api repos/tophtab/nga-just-works/actions/permissions
gh api --paginate repos/tophtab/nga-just-works/releases
gh run list --repo tophtab/nga-just-works
```

## Stop Conditions

- A local or remote expected ref changed after its snapshot.
- A commit is nonlinear or contains an unsupported signed/extra header.
- Any mapped tree, identity, timestamp, message, or post-root diff differs.
- The working-tree/index snapshot changes before local ref movement.
- A workflow is running when Actions would be disabled.
- GitHub rejects atomic push or explicit leases.
- A Release or asset cannot be matched exactly after publication.
- Actions permissions cannot be restored to their prior value.

No later step proceeds across a failed stop condition. Rollback uses the verified bundle, ref snapshot, and remote backup branch from step 1.
