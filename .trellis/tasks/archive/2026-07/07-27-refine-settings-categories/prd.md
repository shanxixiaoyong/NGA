# 细分设置页面分类

## Goal

将设置首页中目前集中在“通用设置”下的选项按用途重新归类，让外观、通知、维护及域名与账号相关选项更易查找，同时保持现有偏好行为不变。

## Background

- 当前设置首页由 `nga_phone_base_3.0/src/main/res/xml/settings.xml` 定义。
- 现有“通用设置”同时包含域名、账号、外观、通知、屏蔽和缓存选项。
- “字体”和“头像大小”当前共用“调整字体和头像大小”子页面，而不是两个独立入口。
- 当前通知选项的界面文案为“启用被喷提示”和“提示声音”，后者依赖前者。

## Requirements

- R1: 新增“外观设置”分类，包含“夜间模式”“夜间模式跟随系统”“纯净背景”“主题风格”和现有“调整字体和头像大小”入口。
- R2: 新增“通知设置”分类，包含“启用被喷提示”和“提示声音”。
- R3: 新增“其他设置”分类，包含“屏蔽规则”和“清除缓存”。
- R4: 将原“通用设置”分类重命名为“域名与账号”，且该分类仅保留“NGA域名”和“账号管理”。
- R5: 保留“主题列表设置”“主题详情设置”“发帖设置”和“实验室”的现有内容与顺序。
- R6: 仅调整设置分类和分类标题；不得改变偏好键、默认值、条目值、依赖关系、点击处理或子页面导航。

## Acceptance Criteria

- [x] AC1: 设置首页按新的分类展示所有现有设置项，没有选项丢失或重复。
- [x] AC2: 外观设置包含 R1 列出的全部外观相关入口。
- [x] AC3: 通知设置包含两个现有通知项，且“提示声音”仍依赖“启用被喷提示”。
- [x] AC4: 其他设置包含“屏蔽规则”和“清除缓存”，两者原有行为不变。
- [x] AC5: 重命名后的原通用分类只包含“NGA域名”和“账号管理”。
- [x] AC6: 主题列表、主题详情、发帖和实验室相关设置不发生行为变化。
- [x] AC7: Android 资源处理及相关设置契约测试通过。

## Out of Scope

- 拆分“调整字体和头像大小”子页面中的字体与头像控制。
- 修改通知机制、缓存清理内容、屏蔽规则或账号管理实现。
- 调整偏好存储格式、默认值或迁移历史配置。
- 对设置页面进行 Compose 迁移或视觉重设计。

## Key Decisions

- 新分类沿用当前设置页的分组式结构，不新增独立的二级分类页面。
- “夜间模式”与“夜间模式跟随系统”属于同一外观功能，因此一并移入“外观设置”。
- 原“通用设置”分类使用用户指定的“域名与账号”名称。
