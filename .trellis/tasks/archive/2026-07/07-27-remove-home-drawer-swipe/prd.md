# 移除首页侧栏滑动手势

## Goal

移除首页所有通过滑动打开侧栏的入口，包括已发布的 24dp 左边缘手势和未提交的全页方向仲裁原型；侧栏仅由首页左上角三横线按钮打开。

## Background

- 已发布代码在 `NavigationDrawerFragment` 中使用 24dp 边缘观察器、`systemGestureExclusion` 和分页门控使抽屉可从左边缘打开。
- 已放弃的后续原型在工作区中添加了分页状态回调和全页方向仲裁，这些未提交改动也属于本回退范围。
- Material `ModalNavigationDrawer` 默认允许手势；只删除 24dp 观察器不能保证“关闭时不可滑开”。

## Requirements

- R1. 侧栏关闭时，从首页任意位置、任意方向的水平滑动都不得打开侧栏。
- R2. 删除 24dp 边缘宽度、边缘命中函数、`systemGestureExclusion`、边缘手势状态及其分页门控。
- R3. 删除未提交原型中为全页左滑添加的分页状态回调、方向所有权、重排回调和相关测试。
- R4. 保留首页左上角三横线菜单图标，点击仍使用动画打开同一侧栏。
- R5. 侧栏打开后仍允许向关闭方向拖动，并允许点击遮罩关闭。
- R6. 首页现有版面分页滑动和收藏长按拖拽排序行为保持不变。
- R7. 修正前端组件规范，删除已放弃的边缘手势契约，记录“关闭时禁止滑开，打开时允许关闭手势”。

## Acceptance Criteria

- [ ] AC1 (R1, R2): 侧栏关闭时，左边缘、页面中间和右侧的水平滑动均不打开侧栏。
- [ ] AC2 (R2, R3): 产品代码中不再存在 `DrawerEdgeWidth`、`isWithinDrawerEdge`、`systemGestureExclusion`、`HomeHorizontalGestureOwner` 或用于侧栏打开的分页状态回调。
- [ ] AC3 (R4): 三横线按钮及“打开侧边栏”辅助功能描述保留，点击可打开侧栏。
- [ ] AC4 (R5): 侧栏打开后，向关闭方向拖动或点击遮罩均可关闭。
- [ ] AC5 (R6): “我的收藏”与“魔兽世界”等版面的分页方向、阈值和结果不变；长按收藏项仍只进行排序。
- [ ] AC6 (R7): 前端组件规范与最终行为一致，不再要求任何滑动打开侧栏。
- [ ] AC7: 受影响模块的编译、单测、lint、移除符号静态扫描和 `git diff --check` 通过。

## Out of Scope

- 不删除侧栏本身、三横线菜单入口或侧栏关闭手势。
- 不改变侧栏内容、宽度、颜色或账户信息。
- 不改变版面分页、收藏数据或排序持久化。

## Key Decisions

- `ModalNavigationDrawer.gesturesEnabled` 在侧栏关闭时为 `false`，打开后为 `true`；这使关闭状态没有滑动入口，同时保留拖动关闭和遮罩点击。
- 左上角菜单图标模型是正确的已发布行为，不随手势回退。
- 任务是边界清晰的轻量回退，使用 PRD-only 规划。
