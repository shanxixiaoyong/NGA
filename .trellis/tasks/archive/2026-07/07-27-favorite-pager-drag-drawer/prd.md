# 收藏页跟手拖拽侧栏

## Goal

让侧栏打开手势具备即时、连续的视觉反馈：用户在“我的收藏”分页内容区开始朝侧栏方向拖动后，侧栏立即按手指位移显露；用户无需先完成整次滑动或偶然快速甩动，便能感知侧栏存在并理解该手势。

## Background

- `4.7.2` 的实现只在最终 `Release` 时判断 50% 位移或 400dp/s 速度，再调用 `DrawerState.open()`；拖动过程没有任何侧栏反馈：`TabLayoutWithPager.kt:90-152`。
- 同一实现令关闭状态的 `ModalNavigationDrawer.gesturesEnabled = false`，因此 Material 抽屉自身也不会在拖动期间显露：`NavigationDrawerFragment.kt:299-363`。
- Material3 1.3.2 的 `DrawerState` 公开二元 `open/close` 与 offset 读取，但不公开逐帧 raw-delta/settle 控制；连续跟手不能通过现有“完成后回调”补丁实现。
- 首页现有侧栏宽 280dp，覆盖在内容上并带遮罩；本任务复用其内容、视觉和菜单行为，不重做侧栏信息架构。

## Requirements

- R1. 手势只在“我的收藏”的 `HorizontalPager` 内容区生效，不覆盖工具栏、标签栏或其他首页区域，也不恢复 24dp 边缘限定。
- R2. 在 LTR 首页中，手指物理向右拖是侧栏方向；一旦方向确定，左侧栏必须在同一指针流中从左边连续跟随手指显露，拖动距离与可见进度连续对应，不等待松手才弹出。RTL 使用对应的 leading 方向。
- R3. 手势未越过方向判定前不得错误抢占垂直滚动；一旦归属侧栏，则由同一个共享拖动状态消费并驱动后续位移。
- R4. 松手后按 Material 对等的位置/速度门槛结算到完全打开或完全关闭；取消手势回到起手前的稳定状态。
- R5. 在 LTR 首页中，手指物理向左拖继续完全交给 Pager，从“我的收藏”进入“魔兽世界”；从第 1 页或更后页面起手时，不得跳过收藏页直接打开侧栏。
- R6. 收藏项长按排序激活时，排序独占手势，不打开侧栏也不切换分页。
- R7. 左上角三横线点击、侧栏打开后的拖动关闭、点击遮罩关闭、系统返回关闭和辅助功能语义保持可用。
- R8. 仅首页使用连续拖拽容器；不得依赖 Material 内部 API、反射、竞态式重组门控或 `systemGestureExclusion`。
- R9. 侧栏继续作为覆盖在静止首页内容上的 280dp modal sheet，遮罩透明度随打开进度变化；不把首页内容整体推移。
- R10. 完成后按现有发布流程提交、finish-work、推送 `main`，创建并推送稳定 annotated tag `4.9.0`，确认正式 Release 构建成功。

## Acceptance Criteria

- [ ] AC1 (R1, R2): 从收藏页内容区左、中、右任意位置起手，朝侧栏方向移动后，侧栏在手指未抬起时已部分可见，且可见进度随位移连续变化。
- [ ] AC2 (R3): 纵向占优的滚动不移动侧栏；方向确定为侧栏后，Pager 不再同时响应该指针流。
- [ ] AC3 (R4): 短距离慢拖松手回弹关闭；越过位置门槛或达到速度门槛后完成打开；取消恢复起手稳定状态。
- [ ] AC4 (R5): 收藏页向后续版面的原手势仍进入“魔兽世界”；后续页面先逐页回到收藏页，不直接打开侧栏。
- [ ] AC5 (R6): 收藏长按排序期间，水平移动只改变收藏顺序，不移动侧栏或分页。
- [ ] AC6 (R7): 菜单按钮仍打开同一侧栏；打开状态仍可拖动、遮罩点击或返回关闭，菜单辅助功能文案不变。
- [ ] AC7 (R8): 产品代码不存在 24dp 边缘逻辑、`systemGestureExclusion`、Material 内部访问或反射；方向、锚点、结算、取消、多指、RTL、排序互斥和辅助功能均有自动化覆盖。
- [ ] AC8: 受影响模块编译、单测和 lint 通过；无设备/模拟器时明确保留真实手势回放门槛。
- [ ] AC9 (R9): 拖拽过程中首页内容位置不变，侧栏从 leading 边缘覆盖出现，遮罩从透明连续加深；完全关闭时侧栏和遮罩均不可见且不拦截内容。
- [ ] AC10 (R10): `main` 与 annotated tag `4.9.0` 指向 finish-work 后的最终提交并推送，tag 工作流成功发布签名 APK 和 SHA-256 文件。

## Out of Scope

- 不改变侧栏内容、280dp 宽度、颜色、头像或菜单项。
- 不改变版面顺序、收藏数据、排序行为或持久化。
- 不把侧栏加入 `HorizontalPager` 成为普通全屏页。
- 不把首页专用容器推广到其他页面或重写全局导航架构。
- 不改写 GitHub Actions 发布流程或手动管理版本号；稳定版身份继续由 tag/CI 注入。

## Key Decisions

- 用户明确选择标准物理方向：LTR 下手指向右拖出左侧栏，向左拖进入后续 Pager 页面。
- 侧栏必须跟手覆盖首页内容，并用同步遮罩提供即时可发现性；“松手后才弹出”的 `4.7.2` 行为被替换。
- 继续保留现有 50% 位置门槛、400dp/s 速度门槛和 256ms 结算动画手感。
- 当前没有未决的产品、范围或发布问题。
