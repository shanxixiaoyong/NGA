# 首页栏次顺序与自定义排序

## Goal

在收藏板块保持固定和完全兼容的前提下，为五个后续首页栏次提供新的默认顺序，并允许用户通过长按顶部栏次标签直接拖动排序，保存为 App 级全局偏好。

## Background

仓库当前将固定的 `bookmark/收藏板块` 放在首页 Pager 第 0 位，再按 `board_list.json` 顺序追加本地栏次。现有稳定 ID/名称为 `wow/魔兽世界`、`other/网事杂谈`、`bliz/暴雪游戏`、`games/游戏专版`、`club/国家地理俱乐部`。

收藏板块和表情排序均采用“短按保持原动作，长按成立后直接拖动，松手保存”的模式。用户已确认“魔兽游戏”为笔误，本任务保留现有 `bliz/暴雪游戏` 名称。

## Requirements

- R1. `bookmark/收藏板块` 始终固定在第 0 位，不参与首页栏次排序；其内容、内部排序和所有既有手势保持不变。
- R2. 没有有效自定义配置时，五个后续栏次按稳定 ID `other`、`games`、`wow`、`bliz`、`club` 展示，对应名称为网事杂谈、游戏专版、魔兽世界、暴雪游戏、国家地理俱乐部。
- R3. 用户短按顶部栏次标签仍切换页面；长按任一非收藏标签后可直接横向拖动调整这五个栏次的相对顺序，不新增独立排序页面或设置入口。
- R4. 长按成立后才临时禁止 Pager 横滑；释放、取消、组件销毁或保存失败后必须恢复 Pager。收藏页侧栏手势与收藏卡片拖动仲裁保持原合同。
- R5. 拖动过程中使用栏次稳定 ID 维持身份；排序后当前正在查看的逻辑栏次保持选中，不因索引变化跳到另一个栏次。
- R6. 自定义顺序按稳定 ID 保存为 App 级偏好，不随 NGA 账号切换。顺序等于默认值时清除冗余偏好。
- R7. 读取偏好时忽略未知和重复 ID，将当前默认列表中缺失的 ID 按默认相对顺序追加，最终始终得到无丢失、无重复的完整五项排列。
- R8. 新默认顺序必须对旧安装中未自定义的用户生效；更新 `board_list.json` 时同步升级本地数据版本，避免继续读取旧缓存顺序。
- R9. TalkBack 为每个非收藏标签提供左移、右移、移到最前和移到最后的等价操作，目标范围不包含收藏板块。
- R10. 保存失败时仅回滚仍对应本次候选顺序的事务，不覆盖更晚的用户操作，并给出可理解的失败提示。

## Acceptance Criteria

- [ ] AC1（R1-R2）：首次或无自定义配置启动时，首页严格展示“收藏板块、网事杂谈、游戏专版、魔兽世界、暴雪游戏、国家地理俱乐部”。
- [ ] AC2（R3-R5）：短按标签正常切页；长按非收藏标签后可横向拖动，拖动期间不翻页，结束后 Pager 立即恢复，当前逻辑栏次保持选中。
- [ ] AC3（R1）：收藏板块不能被移动，其内部收藏拖动、侧栏打开和分页边界行为没有回归。
- [ ] AC4（R6-R8）：完成排序后重新进入首页或重启应用仍保持；账号切换不重置；旧安装无偏好时采用新默认顺序。
- [ ] AC5（R7）：空、损坏、重复、未知或缺项配置均恢复为完整五项，且不会崩溃、丢项或重复。
- [ ] AC6（R9）：TalkBack 可完成与指针拖动等价的左右/首尾移动。
- [ ] AC7（R10）：持久化失败会安全回滚当前事务，不覆盖更新的操作。
- [ ] AC8：纯逻辑与源码合同测试覆盖默认合并、移动、容错、固定收藏页、可选组件 API、手势终止路径和选中栏次稳定性。

## Out of Scope

- 修改收藏板块内部收藏项的排序实现或持久化格式。
- 新增首页排序设置页、重置按钮或跨设备同步。
- 重命名“暴雪游戏”或修改栏次子版面内容。
- 让远端分类接口控制用户自定义的顶层顺序。
