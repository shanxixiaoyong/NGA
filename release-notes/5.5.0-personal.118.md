# NGA 5.5.0-personal.118

基于已发布的 personal.117，仅增加第0页显示开关，保留原有其他功能与网络链路。

## 使用方式

- 打开“设置 → 主题详情设置 → 显示第0页（高赞回复）”。
- 默认开启，保留原有 NGA 高赞预览页。
- 关闭后重新打开帖子，不再出现第0页，普通分页从第1页开始；已有阅读进度仍按原规则恢复。
- 重新开启并重新打开帖子，即恢复原有第0页。
- 不影响 LINUX DO、只看作者、单条回复、搜索或缓存帖子的分页方式。

## 构建

- 版本名：`5.5.0-personal.118`
- versionCode：`50500118`
- 使用原个人发布证书，可覆盖安装 personal.117。
- Release APK 与本标签的源代码对应；调试验收入口仅在 debug 构建中存在。
- 构建沿用项目的签名环境变量，以 `CI_VERSION_NAME=5.5.0-personal.118` 和 `CI_VERSION_CODE=50500118` 调用 `:nga_phone_base_3.0:assembleRelease`。

## 验证

- Debug 构建通过；Android 35 模拟器验证真实设置持久化，以及开启、关闭、再开启时的请求页码、页数、页码选择、楼层恢复和特殊路由。
- 应用单元测试共 267 项，265 项通过。两个失败来自 `LinuxDoAuthFlowTest` 在 JVM 环境调用未模拟的 `JSONObject.quote`；已在完全未修改的 personal.117（`0f39242c`）独立复现相同两项失败。本次未修改登录、网络或 JSON 行为。
