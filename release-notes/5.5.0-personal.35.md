# NGA 5.5.0-personal.35

这是基于 NGA Just Works `5.5.0` 的个人增强 Release。本版重点完善
LINUX DO 登录与原生互动，并用网页恢复解决 NGA 偶发截断 JSON 无法完整
阅读的问题。

## 新增

- LINUX DO 侧边栏账号登录；登录后原生列表可读取账号等级允许查看的主题，
  日常进入板块不再先跳网页登录页。
- LINUX DO 原生回复、点赞和 Boost。每一楼的快速回复按钮默认针对当前楼层
  发起 Boost，“更多”菜单仍保留“回复本楼”和“Boost 回复”两种选择。
- LINUX DO 主题列表展示分类与标签，楼层展示信任级别、徽章或头衔，并支持
  原论坛的简短 Boost 回复样式。
- 所有板块支持关注帖子；关注帖出现新回复时置顶并显示关注标记，看完、
  取消关注或屏蔽后恢复正常。
- NGA 原生 JSON 被服务端截断时，自动读取同帖网页并转换为原生楼层数据，
  继续复用原生排版、翻页和阅读进度。

## 删除

- 删除对截断 JSON 进行补引号、补括号或猜测尾部内容的修复逻辑；缺失的
  正文不再被应用臆造。
- 删除 NGA 与 LINUX DO 楼层的实时属地请求，恢复原版“级别 / 威望 / 发帖”
  布局，避免资料接口频率限制影响正常阅读。
- LINUX DO 快速回复不再弹普通回复框，改为一步进入当前楼层的 Boost 编辑框。

## 修复

- 修复 Retrofit 可选 Header map 为空导致所有帖子报错的问题，并为 NGA
  完整 JSON、截断 JSON、网页恢复和最终浏览器回退建立分层错误保护。
- 修复 LINUX DO 普通网络下正文可读取但作者头像无法加载的问题；普通头像
  与 Boost 小头像统一走板块专用 DoH/QUIC 通道，并加入有界缓存与并发合并。
- 修复 Boost 头像远大于文字的问题，使头像与同一行文字行高一致。
- 修复 LINUX DO 图片链接正文残留、加载慢、异常占位、图片拉伸与左右贴边，
  图片和视频保持正文宽度及原始比例。
- 修复 LINUX DO 点赞数、标签换行、帖子内边距及网页恢复楼层正文贴边等显示
  问题；加载语、主题色绿点、刷新颜色和加载动画保持统一。
- Release 继续使用 R8 压缩、正式包名和个人固定签名，可从此前同签名个人版
  直接覆盖升级。
