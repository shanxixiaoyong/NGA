## 新增

- 首页栏次支持长按顶部标签直接拖动排序；收藏板块固定在首位，排序结果跨账号保存，并提供 TalkBack 左移、右移、移到最前和移到最后操作。默认顺序调整为「收藏板块、网事杂谈、游戏专版、魔兽世界、暴雪游戏、国家地理俱乐部」。
- 在线主题阅读会静默预读取当前页之后最多两页，并始终跳过最后一页，减少连续翻页等待，同时保证真正打开末页时获取最新回复。
- 当前主题页签支持长按刷新：按下后立即刷新，持续按住时每 5 秒再次刷新，松开后停止；短按当前页签仍只回到顶部。

## 删除

- 移除加载界面的随机「加载语」文案，统一为简洁的进度提示。

## 修复

- 恢复 Android 10（API 29）安装支持，同时保持 targetSdk 35、arm64-v8a、应用 ID 和签名方式不变。
- 板块页的发帖按钮和主题页的回复按钮不再随滚动隐藏；主题末尾内容可滚动到回复按钮上方，避免最后一层被遮挡。
- 清除全仓 Android 模块遗留的 12 个 Lint 错误，修正个人资料结果回调、Fragment 参数与确认框上下文读取、列表观察者生命周期等问题；13 个 Android 模块均达到 0 Error / 0 Fatal。
